# Offensive Security Portfolio

Welcome to my offensive security portfolio. This repository contains a collection of my penetration testing reports, lab notes, and vulnerability assessments from various Capture The Flag (CTF) environments.

## 🎯 Purpose
I am an aspiring penetration tester using this repository to document my practical learning journey. It showcases my ability to apply offensive security methodology—from reconnaissance and enumeration to exploitation and privilege escalation. 

More importantly, it demonstrates my focus on translating technical findings into structured reports, including CVSS scoring, business impact, and actionable remediation strategies.

## 🛠️ Skills Demonstrated
*   **Enumeration:** Nmap, Netcat, SMB, FTP, MySQL, Web Fuzzing.
*   **Web Exploitation:** Burp Suite, SQL Injection, LFI, API testing.
*   **System Exploitation:** Metasploit, manual exploitation, misconfigurations.
*   **Privilege Escalation:** Linux (SUID, Cron, Capabilities) and Windows (UAC Bypass, Kernel Exploits, UDF).
*   **Reporting:** Executive Summaries, CVSS 3.1 Scoring, Remediation Roadmaps.

## ⚠️ Disclaimer
**All machines documented in this repository are retired environments.** No active CTF machines are included, in strict compliance with platform rules. All tools, techniques, and payloads are used strictly for educational and ethical purposes.
